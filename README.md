# artifact-template-photo-wall

一个用于生成生活照照片墙、照片容器和纪念性拼贴场景的图像生成 Skill。

它的核心流程是：根据照片内容和构图为每张生活照选择合适的纸质材质，再将照片与背景场景融合。最终图片由支持实际图像输入的图像模型生成，不使用脚本拼接或抠图。

## 工作方式

1. 识别生活照、背景图和可选风格参考，记录每张照片的编号及需要保护的内容。
2. 根据照片内容、横竖比例、情绪和构图，为每张照片选择材质。默认混合 2–3 种，有主有次，不机械平均分配。
3. 根据当前图像工具的真实输入上限选择路线：
   - 输入足够时，一次完成不同材质处理与场景融合。
   - 需要逐张精修或独立素材时，先处理照片，再融合。
   - 输入不足时，移除可选参考后分批、分组或制作多张成品，并在有实质取舍时先确认。
4. 对照原图、背景和生成结果，检查照片数量、人物与宠物身份、材质效果、背景结构、留白和可读性。

详细规则见 [`SKILL.md`](SKILL.md)。纸质材质和提示词模板见 [`references/paper-treatments.md`](references/paper-treatments.md)。

## 支持的纸质材质

- `matte-print`：哑光相纸、细颗粒、轻微柔化。
- `torn-edge`：手撕纤维边、暖米色纸和印刷颗粒。
- `instant`：拍立得白框和宽下边、轻微化学褪色。
- `film-border`：黑胶片边和细腻胶片颗粒。

材质同时作用于纸边和照片内部。整体光线与色调保持协调，但不同材质的边缘、颗粒和褪色效果应保持可辨识。用户指定统一材质时，以用户要求为准。

## 背景场景

“照片墙”是任务统称，不默认等于白墙。可使用：

- 白墙
- 木框或卡纸框
- 桌面
- 挂绳与木夹
- 铁盒

用户提供的背景优先使用。未指定时，根据照片数量、比例、内容、情绪和用途选择场景，并说明选择理由。参考图用于指导风格或构图时，不得带入其中的人物、文字或水印；如果根据参考重新生成背景，必须明确说明不是保留原背景。

现有场景素材位于 [`assets/backdrops/`](assets/backdrops/)，成品风格参考位于 [`assets/frames/`](assets/frames/)。使用前应实际查看图片，不能仅凭文件名判断效果。背景素材是可选场景输入，不设默认白墙；风格参考不等于实际背景，参考重生成的场景需如实说明。图像输入上限以当前工具、当前输入方式为准。

## 输入与文件规则

- 原照片必须作为实际图像输入，不能用文字描述代替未传入的照片。
- 背景、原图、处理图、风格参考和上一轮合成图都占用当前工具的输入位。
- 分批融合时，上一轮场景占一个输入位；若工具上限为 `K`，还要扣除附加参考和重传图片，剩余容量才是本轮可新增的照片数。每轮追踪原图 ID、材质、批次与最终位置，并核查已累计的照片。
- 不静默漏图、不制作低清拼接参考图掩盖输入超限、不擅自更换用户指定背景。
- 不使用脚本生成、拼接或抠图；需要图像处理时使用支持图像输入的模型或工具。
- 不覆盖原图，生成结果使用新的目录或唯一文件名。

## 配置

[`artifact-template.json`](artifact-template.json) 提供场景、材质、版式和情绪的可发现配置；它不规定固定背景、固定材质或固定的模型输入上限。

## 当前限制

实际生成质量取决于所用图像工具是否支持原图引用、多图输入、续轮编辑和结果查看。生成前必须核实这些能力；如果工具无法接收必要图像，应说明限制并暂停，不用文字生图或脚本拼接替代。
